## 🚨 Problem

- Developers spend hours on manual code review  
- Security issues (SQL injection, XSS) slip through  
- Performance bugs appear in production  
- Code quality slowly degrades  

---

## ✅ Solution

AuditX automates code review using AI:


---

## ✨ Features

- 🔍 AI Code Review  
- 🐙 GitHub PR / Repo support  
- 🔴 Severity levels (Critical / Warning / Info)  
- 🏷️ Categories (Security, Bug, Performance, Style, Maintainability)  
- 📊 Code Health Score (0–100)  
- 💡 Fix suggestions  
- ⬇️ Export report (.txt)  
- 🌙 Dark modern UI  

---

## 🛠️ Tech Stack

- React + Vite  
- Node.js + Express  
- Google Gemini 1.5 Flash / Ollama  
- GitHub API
